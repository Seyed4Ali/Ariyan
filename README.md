# Ariyan — داشبورد و ربات محلی متاتریدر

Repository: https://github.com/Seyed4Ali/Ariyan

**برای ادامهٔ کار روی دستگاه جدید:** اول همین README و سپس [راهنمای ادامه برای دستیار](docs/AGENT-HANDOFF.md) را بخوانید. کاربر گفته متاتریدر دستگاه دوم از قبل به همان حساب دموی خودش وارد است؛ اتصال موجود را بررسی کنید و درخواست رمز نکنید.

داشبورد فارسی، خوراک مستقیم MetaTrader 5، سه نماد EURUSD / XAUUSD / BTCUSD، شبیه‌سازی با سرمایهٔ اولیهٔ حساب دمو، اجرای اختیاری روی دموی بروکر و چک‌لیست آماری یادگیرنده.

## راه‌اندازی روی دستگاه جدید

1. Windows 64-bit، Python 3.13 64-bit با گزینهٔ Add Python to PATH و MetaTrader 5 بروکر را نصب کنید.
2. پروژه را در یک پوشهٔ قابل نوشتن استخراج کنید یا از مخزن خصوصی clone بگیرید.
3. `Setup-Arian.cmd` را اجرا کنید. بسته‌های پایتون در `.venv` همین پروژه نصب می‌شوند.
4. در خود متاتریدر وارد حساب دمو شوید؛ رمز را داخل کد، GitHub یا گفتگو ننویسید.
5. `terminal_path` و نام نمادها را در `config.json` بررسی کنید. پیش‌فرض مخصوص FxPro است: EURUSD، GOLD و BITCOIN. پروفایل ساعت بروکر هم باید درست باشد.
6. `Start-Arian.cmd` را اجرا و [داشبورد](http://127.0.0.1:8765/) را باز کنید.

اگر پوشهٔ پروژه در Codex روی دستگاه جدید باز است، دستیار می‌تواند نصب، بررسی مسیر MT5، شروع سرور و بررسی API را از همان پوشه انجام دهد. `localhost` هر دستگاه به خودش اشاره می‌کند؛ آدرس بالا پس از اجرای سرور روی دستگاه جدید فعال می‌شود.

تایم‌فریم‌های نمودار: M1، M2، M3، M4، M5، M6، M10، M12، M15، M20، M30 و H1. ورود اسکالپ همچنان از کندل بسته‌شدهٔ M1 و روند M5 استفاده می‌کند. انتخاب تایم‌فریم نمودار، مجوز یا استراتژی ورود را تغییر نمی‌دهد.

پروژه با حالت SHADOW شروع می‌شود. برای اجرای بروکر، همان حساب باید دمو با ارز USD باشد، Algo Trading روشن باشد و اجرای دمو از داشبورد فعال شود. بررسی معتبر تقویم اخبار و سایر کنترل‌های ریسک نیز لازم‌اند. اجرای حساب واقعی در دروازهٔ سفارش مسدود است.

## انتقال سوابق و آموخته‌ها

کد با GitHub منتقل می‌شود؛ پایگاه‌دادهٔ خصوصی جداگانه. [راهنمای کامل انتقال](docs/transfer-fa.md) روش تهیه و بازگرداندن backup را توضیح می‌دهد. بستهٔ سورس شامل پایگاه‌داده، رمز، حساب، گزارش خصوصی، تاریخچهٔ بازار یا گفتگوهای مرجع نیست. برای ادامهٔ همان حافظه، backup خصوصی را هم منتقل و در همان حساب دمو وارد شوید.

هم‌زمان دو موتور فعال روی یک حساب اجرا نکنید. پیش از جابه‌جایی، ورود دستگاه قدیمی را متوقف کنید، خروج/وضعیت پوزیشن‌ها را بررسی کنید و سرور قدیمی را ببندید. انتقال database، مجوز اجرای دمو را فعال نمی‌کند.

## ریسک و محدودیت

سقف ریسک هر معامله ۰٫۲۵٪، توقف ورود در زیان روزانهٔ ۱٪، افت از اوج ۵٪، حداکثر یک پوزیشن و شش ورود در روز، فاصلهٔ پنج دقیقه پس از خروج و حداکثر هشت دقیقه نگهداری. گپ، لغزش، هزینه و قطع اتصال می‌توانند زیان را از بودجه بیشتر کنند. SL/TP بروکر پس از قطع برنامه باقی می‌ماند؛ خروج زمانی به روشن‌بودن برنامه نیاز دارد. کارمزد فرضی باید با نوع حساب و نماد تطبیق داده شود.

سودآوری تضمین یا اثبات نشده است. ایجنت آماری فقط می‌تواند پس از آموزش، اعتبارسنجی و آزمون آینده، زمینه‌ای را در شبیه‌سازی حذف کند؛ ریسک و مجوز بروکر را تغییر نمی‌دهد. قوانین ورود در [چک‌لیست](docs/checklist-fa.md) آمده‌اند.

## بررسی کد

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

مخزن GitHub برای نگهداری و انتقال سورس است. موتور این نسخه روی Windows و ترمینال محلی اجرا می‌شود؛ انتشار فایل‌ها به‌تنهایی ربات را همیشه‌روشن نمی‌کند.

## نقشهٔ پروژه برای ادامهٔ توسعه

| مسیر | نقش |
|---|---|
| `server.py` | سرور HTTP و API روی `127.0.0.1:8765` |
| `config.json` | نمادها، مسیر MT5، پروفایل ساعت، ریسک و سشن‌ها |
| `arian/mt5_worker.py` | خواندن قیمت و حساب از ترمینال؛ دروازهٔ اجرای فقط دمو |
| `arian/feed.py` | اجرای IPC جدا، مهلت پاسخ، کش کندل مختص حساب |
| `arian/engine.py` | حلقهٔ موتور، دفتر حساب، تطبیق سفارش و کنترل‌ها |
| `arian/strategy.py` | ستاپ روند M5 و شکار نقدینگی/تأیید ساختار M1 |
| `arian/paper.py` / `risk.py` | پرشدن شبیه‌سازی، حجم، هزینه و محدودیت ریسک |
| `arian/learning.py` | چک‌لیست آماری، اعتبارسنجی و آزمون آینده؛ اعمال فقط در شبیه‌سازی |
| `arian/storage.py` | SQLite و ذخیرهٔ معاملات، وضعیت و نسخهٔ قانون |
| `web/` | داشبورد فارسی؛ سه نماد و ۱۲ تایم‌فریم |
| `scripts/` | نصب، شروع/توقف، backup و بستهٔ انتقال |
| `tests/` | آزمون‌های هسته، حساب، دسترسی، ایجنت و تایم‌فریم‌ها |

در نسخهٔ تحویل‌داده‌شده ۳۸ آزمون پاس شده‌اند و خوراک هر سه نماد از FxPro بررسی شده است. این وضعیت، تأیید سودآوری یا اجرای واقعی سفارش نیست. آزمون سفارش دمو/واقعی با پول کاربر انجام نشده است. نتیجه‌های پژوهش محلی، database و نشست Git/MT5 در این مخزن قرار نمی‌گیرند.
