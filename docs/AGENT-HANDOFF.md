# به‌روزرسانی ۱۲ نوامبر ۲۰۲۶

کلید demo_daily_stops هر دو توقف زیان روزانه و زیان متوالی را فقط برای حساب دموی متصل و همین نشست کنترل می‌کند؛ مجوز آن به حساب دیگر یا restart منتقل نمی‌شود.

پیش از دستورهای قدیمی پایین، docs/fast-demo-fa.md را بخوانید. دانلود ممیزی تیک تاریخی دیگر در snapshot زنده نیست. پروفایل fast-demo و ساعت برنامه با HTTPS Date پشتیبانی می‌شوند. مجوز اجرا پس از restart خاموش است. مبنای آزمون تازه فقط با تأیید صریح کاربر ساخته شود؛ تغییر موتور نباید افت قبلی را پاک کند. گزارش مقایسهٔ ریپازیتوری‌ها در docs/repository-review-fa.md است. database و هیچ اطلاعات حسابی در سورس یا ZIP کد قرار نگیرند.

# راهنمای ادامهٔ Ariyan روی دستگاه جدید

این فایل برای دستیار بعدی نوشته شده تا با لینک مخزن، پروژه را از روی شواهد محلی راه‌اندازی کند. کد این مخزن منبع رفتار برنامه است؛ قبل از تغییر، README و config را بخوانید.

## هدف کاربر

- داشبورد فارسی برای رصد EURUSD، XAUUSD و BTCUSD از حساب متاتریدر خودش.
- متاتریدر دستگاه جدید طبق گفتهٔ کاربر از قبل به **همان حساب دمو** متصل است. از نشست موجود استفاده کنید؛ رمز حساب در مخزن نیست و نباید از متن گفتگوهای قدیمی بازیابی شود.
- سرمایهٔ اولیهٔ دو حساب شبیه‌سازی با بالانس حساب دموی متصل هم‌اندازه می‌شود. بالانس، اکوئیتی و مارجین آزاد خود بروکر هم جدا نشان داده می‌شوند.
- نمودارهای M1 تا H1، اسکالپ چنددقیقه‌ای، ژورنال ماندگار و ایجنت آماری چک‌لیست. هیچ سود ثابتی وعده داده نشده است.
- بخش «سشن و اخبار» شامل ویجت‌های فارسی FinanceKit استفاده‌شده در دو صفحهٔ ایران‌ریبیت است. نشانی‌ها و تنظیمات در `arian/market_tools.py` و مسیر API عمومی محلی `/api/market-tools` هستند؛ [جزئیات](market-tools-fa.md).

## راه‌اندازی سریع

1. پوشهٔ همین checkout را workspace قرار دهید. Windows 64-bit و Python 3.13 64-bit لازم‌اند. ابتدا وجود ابزارها و نسخه را بررسی کنید.
2. `config.json` را بخوانید. مسیر پیش‌فرض `C:\Program Files\MetaTrader 5\terminal64.exe` است؛ اگر ترمینال در محل دیگری نصب است، مسیر واقعی نصب را پیدا و فقط مقدار `terminal_path` را اصلاح کنید.
3. اگر `.venv\Scripts\python.exe` و وابستگی‌ها آماده نیستند، `Setup-Arian.cmd` یا `scripts/Setup-Arian.ps1` را اجرا کنید. رمز، توکن و هویت حساب را در کد ننویسید.
4. از Python همان محیط، اتصال خواندنی را با `MT5Feed(config).snapshot()` بررسی کنید. نصب بسته به معنی اتصال حساب نیست. باید حساب واقعاً متصل، نوع آن demo و ارز آن USD باشد؛ شمارهٔ حساب را فقط محلی بررسی کنید.
5. نمادهای بررسی‌شدهٔ FxPro: `EURUSD`، `GOLD` و `BITCOIN`؛ نام‌های نمایشی XAUUSD/BTCUSD هستند. با ETF بیت‌کوین اشتباه نشوند. اگر ابزار دیگری در بروکر دیده شد، از مشخصات واقعی آن استفاده کنید.
6. پروفایل ساعت `fxpro-eu`، GMT+2 زمستان/GMT+3 تابستان با تغییر ساعت اروپا، برای اتصال قبلی بررسی شده است. زمان تیک پس از تبدیل باید تازه باشد؛ اختلاف ساعت را با فرض تازه‌بودن یک تیک کهنه حدس نزنید.
7. اگر کاربر backup خصوصی ارائه کرده، **پیش از شروع سرور** دستورهای انتقال پایین را دنبال کنید. اگر backup ندارد، دفتر تازه ساخته می‌شود؛ آموخته‌های دستگاه قبلی خودبه‌خود از GitHub بازیابی نمی‌شوند.
8. پیش از شروع موتور دستگاه جدید، مطمئن شوید موتور دستگاه قبلی برای همین حساب دیگر فعال نیست؛ این برنامه قفل چنددستگاهی ندارد. اگر وضعیت قبلی معلوم نیست، ادامهٔ نصب و اتصال خواندنی ممکن است، اما ورود خودکار را فعال نکنید.
9. `Start-Arian.cmd` را اجرا کنید. یا برای اجرای مستقیم و بررسی log: `.\.venv\Scripts\python.exe server.py`. سرور روی loopback پورت 8765 است. اجرای دوباره روی همان پورت موتور دوم ایجاد نمی‌کند.
10. پاسخ `GET http://127.0.0.1:8765/api/state` و صفحهٔ اصلی را بررسی کنید. اگر روی دستگاه دیگری هستید، `127.0.0.1` دستگاه قدیمی را نشان نمی‌دهد؛ این یک سرور جدید با همان سورس است.

## خروجی لازم برای تأیید راه‌اندازی

در API و داشبورد بررسی کنید:

- `connection.connected = true`، `connection.demo = true` و ارز USD؛ بالانس/اکوئیتی از حساب جاری خوانده شوند.
- `capital_binding` موجود باشد و سرمایهٔ اولیه از بالانس حساب دمو آمده باشد. عدد بالانس روز قبل را در config وارد نکنید. polling و restart نباید سود/زیان شبیه‌سازی را دوباره صفر کنند.
- سه کلید EURUSD، XAUUSD و BTCUSD در `markets` حاضر باشند؛ `spec.symbol` به ابزار درست بروکر اشاره کند.
- `feed_fresh` برای بازار باز true باشد. روی بازار بسته، BLOCK و قیمت قدیمی نتیجهٔ درست است؛ برای گرفتن سیگنال، محافظ تازگی را حذف نکنید.
- `supported_timeframes` شامل M1، M2، M3، M4، M5، M6، M10، M12، M15، M20، M30، H1 باشد. کندل جاری در `current` از کندل‌های بستهٔ `bars` جداست.
- `error` خالی، `real_trading=false` و در شروع `mode=SHADOW` باشد.
- مرورگر را باز و نمودار، انتخاب نماد/تایم‌فریم، اتصال و ژورنال را بررسی کنید. اگر ابزار مرورگر در دسترس نیست، تأیید API را از تأیید بصری جدا گزارش کنید.

## حافظه و انتقال حساب

فایل خصوصی `data/arian.sqlite` شامل معاملات، دفاتر حساب، سرمایهٔ اولیه، نسخه‌های چک‌لیست و کنترل‌های توقف است. `.gitignore` آن را کنار می‌گذارد. نمونهٔ خالی `data/.gitkeep` عمدی است.

برای backup سازگار روی دستگاه قبلی:

```powershell
python scripts/backup_state.py
```

backup را از مسیر خصوصی منتقل و در حالی که سرور جدید متوقف است به `data/arian.sqlite` برگردانید. اگر این فایل از قبل وجود دارد، اول از آن backup بگیرید و بدون بررسی بازنویسی نکنید. فایل‌های WAL، PID، log و `.venv` دستگاه قدیمی را از کپی معمول پوشه وارد نکنید. ورود به همان حساب باعث انتخاب همان دفتر می‌شود؛ حساب دیگر دفتر و حافظهٔ مستقل دارد.

## وضعیت اجرا و محدودیت‌ها

- کاربر ساخت و اتصال ربات دمو را خواسته است. نسخهٔ قبلی در حالت SHADOW بود و Algo Trading ترمینال خاموش تشخیص داده شده بود؛ وضعیت دستگاه جدید را دوباره بخوانید و وضعیت قدیمی را فرض نکنید.
- فعال‌شدن خوراک یا بازیابی database، اجرای دمو را فعال نمی‌کند. این بخش در داشبورد به تایپ DEMO، حساب دموی USD، Algo Trading روشن، حساب بدون پوزیشن/سفارش دیگر و نبود ارسال مبهم قبلی نیاز دارد.
- تقویم اخبار **خودکار نیست**. ورود تا ثبت بررسی دستی معتبر بسته می‌ماند. خودتان بدون بررسی تقویم، پرچم اخبار را تأیید نکنید.
- نمایش تقویم در iframe به معنی تأیید اخبار یا ورود داده به موتور نیست. iframe فقط از `https://widget.financekit.org` و با پیکربندی عمومی فارسی/تهران بارگذاری می‌شود. script و API والد همچنان فقط self هستند؛ اطلاعات حساب را به ویجت‌ها، query string یا postMessage نفرستید. در قطعی اینترنت، لینک صفحات اصلی و ثبت دستی بررسی موجود است.
- حساب واقعی در خود دروازهٔ سفارش رد می‌شود. هیچ guard حساب/تازگی/ریسک را برای نمایش نتیجهٔ بهتر حذف نکنید. retry ورود با پاسخ مبهم خودکار نیست.
- انتخاب تایم‌فریم نمودار فقط نمودار و نمای روند را عوض می‌کند. ستاپ اجرایی M1 با روند M5 است؛ H1 در این نسخه استراتژی ورود مستقل ندارد.
- محدودیت‌ها: ریسک ۰٫۲۵٪، توقف روزانه ۱٪، افت ۵٪، یک پوزیشن بین همهٔ نمادها، ۶ ورود در روز، ۳ زیان متوالی، cooldown پنج دقیقه، زمان خروج هشت دقیقه. FX/طلا ۰۷–۱۷ UTC روز کاری؛ BTC همهٔ روزها مشروط به خوراک تازه و بقیهٔ شروط.
- ایجنت **آماری** است و از ۷۰ آموزش، حدود ۳۰ اعتبارسنجی پاک‌سازی‌شده و ۵۰ معاملهٔ آینده استفاده می‌کند. تغییرات فقط در حساب شبیه‌سازی اعمال می‌شوند. دادهٔ ناکافی را به‌جای احتمال برد یا یادگیری ساختگی گزارش کنید.

## آزمون‌ها و ارائهٔ نتیجه

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

سپس لینک داشبورد محلی، وضعیت واقعی اتصال، وجود سه نماد، سرمایهٔ خوانده‌شده، بازیابی یا تازه‌بودن حافظه و وضعیت اجرای دمو را گزارش کنید. نصب موفق را با اتصال موفق یا ارسال سفارش اشتباه نگیرید. برای تست اتصال، سفارش آزمایشی تحمیلی باز نکنید.
