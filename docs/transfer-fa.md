# انتقال آریان به دستگاه دیگر

## مسیر پیشنهادی

مخزن انتخاب‌شدهٔ کاربر برای این نسخه: [Seyed4Ali/Ariyan](https://github.com/Seyed4Ali/Ariyan). کد در این مخزن نگه داشته می‌شود و backup خصوصی حافظه جدا منتقل می‌شود. [راهنمای ادامه برای دستیار](AGENT-HANDOFF.md) مراحل بررسی اتصال روی دستگاه جدید را مشخص می‌کند. اطلاعات حساب و database را در مخزن عمومی قرار ندهید.

پروژهٔ فعلی برای Windows 64-bit و MetaTrader 5 ویندوز آماده شده است. روی macOS، Linux یا موبایل، این بسته مستقیماً با همین اسکریپت‌ها اجرا نمی‌شود؛ موتور باید روی یک Windows/VPS ویندوز اجرا شود. داشبورد این نسخه فقط روی loopback همان دستگاه در دسترس است و اتصال از موبایل نیازمند تنظیم جداگانهٔ دسترسی امن است.

## دستگاه جدید

1. Python 3.13 64-bit را با گزینهٔ Add Python to PATH نصب کنید.
2. MetaTrader 5 بروکر را نصب و در خود ترمینال وارد همان حساب دمو شوید.
3. کد را از مخزن Private دانلود یا clone کنید؛ پوشه را استخراج کنید.
4. `Setup-Arian.cmd` را اجرا کنید تا محیط پایتون و وابستگی‌ها نصب شوند.
5. مسیر نصب MT5 و نام نمادها را در `config.json` بررسی کنید. پیش‌فرض FxPro: `EURUSD`، `GOLD` و `BITCOIN` است. پروفایل ساعت برای بروکر دیگر باید تغییر کند.
6. اگر backup خصوصی دارید، پیش از اولین اجرای سرور آن را به `data/arian.sqlite` برگردانید. اگر این مسیر قبلاً database دارد، ابتدا از آن پشتیبان بگیرید؛ آن را بی‌بررسی بازنویسی نکنید.
7. `Start-Arian.cmd` را اجرا و `http://127.0.0.1:8765/` را باز کنید.

شماره حساب، بالانس، اکوئیتی، نمادها و تازگی قیمت را در داشبورد بررسی کنید. اجرای بروکر پیش‌فرض خاموش است؛ فعال‌سازی دمو، Algo Trading و بررسی تقویم اخبار جداگانه لازم‌اند.

## انتقال آموخته‌ها و ژورنال

روی دستگاه قدیمی، این دستور backup سازگار از SQLite می‌سازد؛ حتی اگر سرور روشن باشد:

```powershell
python scripts/backup_state.py
```

فایل در `backups/` ساخته می‌شود. برای آخرین وضعیت پیش از جابه‌جایی، ابتدا ورود ربات را متوقف و وضعیت خروج پوزیشن‌ها را بررسی کنید، سرور قدیمی را ببندید و سپس backup نهایی بگیرید. فایل backup را از راه خصوصی مثل حافظهٔ USB منتقل کنید؛ داخل مخزن GitHub نگذارید. این فایل شماره حساب، سوابق و حافظهٔ ایجنت را دارد، ولی برنامه رمز MT5 را در آن ذخیره نمی‌کند.

فقط کپی‌کردن `arian.sqlite` حین اجرای سرور می‌تواند آخرین تغییرات داخل WAL را جا بگذارد؛ از ابزار backup استفاده کنید. فایل‌های `server.pid`، log، `.venv` و cache را به دستگاه دیگر منتقل نکنید. با ورود به حسابی دیگر، برنامه دفتر و حافظهٔ مجزایی انتخاب می‌کند.

هم‌زمان دو نسخهٔ فعال موتور روی یک حساب اجرا نشوند. GitHub این هماهنگی را انجام نمی‌دهد و هیچ فایل رمز یا نشست متاتریدر را هم منتقل نمی‌کند.

## قرار دادن کد در GitHub

بستهٔ سورس آماده را استخراج کنید؛ **محتویات آن** را در مخزن Private بگذارید، نه backup حافظه را. فایل `.gitignore` هم باید همراه کد باشد. این فایل `data/`، `reference/`، `reports/`، `backups/`، `exports/`، `.venv`، فایل‌های محیطی و database را از Git کنار می‌گذارد. فایل‌هایی که قبلاً در Git ثبت شده باشند، تنها با افزودن ignore از تاریخچه حذف نمی‌شوند.

پس از انتقال، لینک مخزن و این متن را در گفتگوی دستگاه جدید بدهید:

> این نسخهٔ پروژهٔ Arian Trader من است. README و docs/transfer-fa.md را بخوان؛ پروژه را روی همین Windows راه‌اندازی کن، MT5 و حساب دموی فعلی را بررسی کن، در صورت ارائهٔ backup خصوصی حافظه را بازیابی کن و نمودار سه نماد را وصل کن. وضعیت اتصال، سرمایه و اجرای دمو را دقیق گزارش کن.
